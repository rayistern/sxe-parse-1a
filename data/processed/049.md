## Prioritization Key

**Use these numbers to prioritize tasks:**

- **1** = Must happen today
- **2** = Could happen tomorrow, much better if it happens today
- **3** = Important, not urgent
- **4** = Can wait
- **5** = Doesn't belong on this list

## Using This Task List

### How to Implement

- Adjust suggested deadlines to your situation
- Earlier is usually better

**3. Assign Responsibility:**
- Use "Who" column
- Delegate where possible

**4. Prioritize:**
- Use 1-5 system
- Focus on 1's and 2's first

**5. Track Progress:**
- Check off completed tasks
- Move forward stalled tasks

**6. Review Regularly:**
- Daily check-ins during peak prep
- Weekly before that
