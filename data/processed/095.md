## Saving and Exporting

### File Formats

**For Print:**
- PDF (best quality)
- PNG (high resolution)
- 300 DPI minimum

**For Digital:**
- PNG (transparent backgrounds)
- JPG (smaller file size)
- 72-96 DPI sufficient

**For Social Media:**
- Use Canva's size presets
- Instagram post: 1080x1080
- Facebook post: 1200x630
- Story: 1080x1920
- Optimize for platform
