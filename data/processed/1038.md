### Purchase Options

**Inflatable Animals:**
- Amazon/party supply stores
- Various sizes available
- Relatively affordable ($50-300 each)
- Easy storage
- Reusable

**Cardboard Standup:**
- Party supply companies
- Event rental companies
- Photo booth prop suppliers
- Customizable
- Less expensive than inflatables

**Stuffed/Plush:**
- Large stuffed animals
- Realistic or cartoonish
- Soft and safe
- Expensive for life-size
- Kids can interact

**Cardboard Construction:**
- Find animal templates online

- Cut out with box cutter
- Paint/decorate
- Add support stand
- Volunteers can help

**Papier-Mâché:**
- Time-intensive
- Craft project with community
- Very customizable
- Lightweight
- Artistic

**Fabric/Costume:**
- Create fabric animals
- Stuff with foam/batting
- Simpler shapes work
- Community sewing project

## Cost Comparison

### Budget Breakdown

**Inflatables:**
- Small (3-4 ft): $50-100
- Medium (5-6 ft): $100-200
- Large (7+ ft): $200-500
- Set of 5-6 animals: $500-1500

**Cardboard Standups:**
- Standard size (5-6 ft): $30-80 each
- Custom printed: $50-150 each
- Set of 5-6: $200-500

**Rental:**
- Per animal: $50-200
- Depends on size/quality
- Delivery fees
- Damage deposit
- Set of 5-6: $300-1000

**DIY:**
- Materials only: $50-200 total
- Time investment significant
- Volunteer labor
- Most budget-friendly

## Placement Strategy

### Where to Put Animals

**Entrance:**
- Welcome guests
- Set the scene immediately
- Photo opportunity arrival

**Photo Booth Area:**
- Multiple animals grouped
- Safari backdrop
- Props (hats, binoculars)
- Designated photographer

**Throughout Venue:**
- Scattered animals
- Different areas
- Create journey feel
- Discover as you explore

**Kids Area:**
- Interactive zone
- Safe for play
- Educational signs
- Handlers (volunteers)

---

## Safety Considerations

### Important Factors

**Inflatables:**
- Secure properly (won't fall)
- No sharp objects nearby
- Supervise children
- Deflation plan if needed

**Cardboard:**
- Stable stands
- Not blocking exits
- Fire safety (away from candles)
- Sharp edges covered

**General:**
- Clear pathways
- No trip hazards
- Weight distribution
- Emergency access maintained

---

## Storage & Reuse

### After Event

**Inflatables:**
- Deflate and clean
- Store in dry place
- Label clearly
- Use for future events
- Loan to other Shluchim

**Cardboard:**
- Carefully store flat
- Protect from moisture
- Can be folded if designed right
- Takes up space
- Multiple year use

**Documentation:**
- Photo inventory
- Condition notes
- Storage location
- Share on Exchange
